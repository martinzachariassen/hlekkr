# frontend — Hlekkr web client

A single-screen client (Vite + React + TypeScript, no UI framework) for the backend API,
served in production by Caddy — the stack's only public service.

- **Setup, configuration, and the backend contract:** [`docs/frontend.md`](../docs/frontend.md)
- **Architecture and security reasoning:** [root README](../README.md)

```bash
pnpm install
pnpm dev            # http://localhost:5173 — or `mise run dev` from the root for the whole stack
```
